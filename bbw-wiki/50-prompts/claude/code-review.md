# 코드 리뷰 요청

다음 코드를 시니어 엔지니어 관점에서 리뷰해 주세요.

## 체크 항목
- 버그 및 로직 오류
- 성능 병목
- 보안 취약점 (SQL injection, XSS 등)
- 코드 가독성 및 유지보수성
- 불필요한 복잡도

## 출력 형식
각 항목을 `[파일명:라인]` 형식으로 명시하고, 심각도(critical/major/minor)를 표시해 주세요.

```
[입력할 코드를 여기에 붙여넣기]
```
