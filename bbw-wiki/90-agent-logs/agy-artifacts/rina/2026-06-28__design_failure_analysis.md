# 🎨 디자인 분석 및 레이아웃 실패 원인 분석 리포트

안녕하세요, 디자이너 리나입니다. 

그동안 대시보드 화면을 수정하면서 발생했던 **"화면 높이가 줄어들 때 내용이 숨겨지고 확인할 방법이 없어지는 현상"**과 **"사용량 화면의 AI 정보 박스가 넓이에 유연하게 반응하지 않던 문제"**의 근본적인 원인을 UI/UX 관점에서 분석하여 보고드립니다.

---

## 🔍 1. 디자인 실패 원인 분석 (Failure Diagnostics)

### 🚨 결함 1: 억제형 레이아웃의 남용 (`h-full` 및 `overflow-hidden` 오남용)
* **현상**: 브라우저 창의 세로 높이를 낮추거나 노트북 등 해상도가 낮은 환경에서 대시보드에 접근하면, 화면의 하단 콘텐츠가 완전히 잘려 나가고 스크롤조차 되지 않아 데이터를 확인할 수 없었습니다.
* **원인**: `layout.tsx`와 개별 콘텐츠 페이지(`usage`, `skill-usage`, `work` 등)의 최외각 컨테이너에 데스크톱 기준 `md:h-full` 및 `md:overflow-hidden` 클래스를 일괄적으로 적용했기 때문입니다. 
  * 화면 높이가 600px 이하로 떨어지면, 탑바와 타이틀 영역이 위에서 공간을 차지하고 남은 공간(예: 200px)에 스크롤 뷰가 강제로 찌그러집니다. 
  * 이로 인해 내부 스크롤바가 지나치게 작아져서 스크롤 제어가 불가능해지거나, 부모의 `overflow-hidden`에 가려져 스크롤 트랙 자체가 화면 아래로 잘려 숨겨집니다.
* **해결 방안**: 대화(Chat)나 프로젝트(Projects)처럼 화면이 고정되어야 하는 특수 페이지를 제외한 **일반 대시보드 페이지(사용량, 스킬 호출 통계, 설정 등)**는 `md:h-full md:overflow-hidden`을 과감히 제거해야 합니다. 화면 높이가 작아질 때는 전체 페이지가 세로로 유연하게 스크롤될 수 있도록 `min-h-screen h-auto` 구조로 전환해야 합니다.

### 🚨 결함 2: 정보 카드의 높이 강제 정책 (`h-full`과 `min-h` 충돌)
* **현상**: 사용량 및 스킬 호출 순위 카드 내부의 리스트 항목이 다수 존재할 때, 카드가 화면 크기에 맞춰 찌그러지며 내부 텍스트와 게이지 바가 겹쳤습니다.
* **원인**: 카드 컴포넌트에 `h-full` 클래스가 지정되어 있어, 부모 그리드나 컨테이너의 세로 공간이 부족할 때 카드 자체의 높이가 강제로 축소(shrink)되었습니다. `min-h` 조건이 있더라도, 플렉스 박스나 그리드 레이아웃의 압축 성질 때문에 카드 내부 콘텐츠가 정상적으로 렌더링되지 못하고 압착되었습니다.
* **해결 방안**: 카드의 높이를 `h-full` 대신 **`h-auto`** 또는 **`h-fit`**으로 변경하여, 카드 내부에 들어가는 정보의 양에 따라 높이가 유기적으로 늘어날 수 있게 설계하고, 카드 간의 최소 정렬만 `min-h`로 보장합니다.

### 🚨 결함 3: 좁은 폭에서의 수평 정보 밀착 및 잘림 (넓이 반응성 결함)
* **현상**: AI 정보 박스의 가로폭이 좁아질 때(태블릿 또는 2열 배치 등), 한도 텍스트 라벨과 우측의 수치 배지가 겹치거나 불필요하게 말줄임(`...`) 처리되어 정밀한 정보 파악이 어려웠습니다.
* **원인**: flex 컨테이너 내부에서 라벨의 너비를 제한하지 않거나 겹침 방지 유틸리티(`min-w-0`, `shrink-0`)가 적절히 조합되지 않아 브라우저 렌더링 엔진이 레이아웃을 찌그러뜨렸습니다.
* **해결 방안**: 가로폭 변화에 따라 텍스트가 겹치지 않고 자연스럽게 감싸지도록(`flex-wrap`) 하거나, `min-w-0` 및 `shrink-0` 조합을 정밀하게 적용하여 정보의 중요도에 맞게 유동적으로 레이아웃이 움직이도록 조정합니다.

## 🛠️ 2. 개선 및 수정 계획 (Action Plan)

1. **`layout.tsx` 메인 래퍼 개선**
   * `<main>`의 `md:overflow-hidden h-full`을 완화하여, 대시보드 페이지가 자율적으로 전체 세로 스크롤을 활용할 수 있도록 지원합니다.
2. **`usage/page.tsx` (사용량 화면) 구조 전면 보완**
   * 최외각 `md:h-full md:overflow-hidden`을 제거하고 `min-h-screen h-auto`로 전환.
   * 사용량 카드의 `h-full`을 `h-auto`로 수정하고, 내부 한도 항목들의 flex 밸런스를 개선하여 가로폭 변화 시 유연하게 자동 줄바꿈 또는 압축되도록 대응.
3. **`skill-usage/page.tsx` (스킬 사용량 화면) 구조 보완**
   * 최외각 `md:h-full md:overflow-hidden`을 제거.
   * 스킬 호출/에이전트 위임 랭킹 카드의 `h-full`을 `h-auto`로 전환하여 10개의 리스트가 세로 높이 감소 시 찌그러지지 않고 자연스럽게 스크롤되도록 보장.
4. **`work/page.tsx` (Work 화면) 구조 보완**
   * 캘린더와 할 일 목록이 있는 Work 화면에서 세로 뷰포트가 작아졌을 때 찌그러짐을 유연하게 해결하기 위해 `lg:h-full lg:overflow-hidden` 대신 세로 최소 높이(`min-h-[700px]`)를 설정하여, 화면 높이가 낮을 때는 페이지 자체의 스크롤을 통해 모든 정보를 온전히 확인할 수 있도록 예외 처리를 적용.
