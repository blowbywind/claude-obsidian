## 요약

빅데이터 분석의 전체 흐름을 실무 사례 중심으로 설명한 입문 강의. YouTube 추천 알고리즘·장바구니 분석·커피숍 이벤트 최적화 사례를 통해 왜 서비스 개발자도 데이터 분석을 알아야 하는지 설명하고, 소규모 구축 가능한 ELK + Python + FastAPI 스택까지 제시한다.

## 핵심 주장

### 실무 사례 3가지

**사례 1 — YouTube 추천 시스템**
- 목표: 사용자 체류 시간 극대화
- 방법: 시청 기록·좋아요·체류 시간 → 딥러닝 학습 → 개인화 랭킹 → 오른쪽 추천 영상
- 교훈: 서비스를 만들 때 "어떤 알고리즘으로 사용자를 더 오래 머무르게 할지"가 핵심 데이터 분석 질문

**사례 2 — 장바구니 분석 (Market Basket Analysis)**
- 데이터 소스: 영수증·결제 내역 (가장 확실한 데이터)
- 유명 예: 기저귀 + 맥주 연관관계 발견 → 진열 배치·번들 추천·캠페인 기획
- 활용: 상품 진열 최적화, 묶음/세트 상품 기획, 연관 추천

**사례 3 — 커피숍 할인율 최적화**
- 질문: 할인을 얼마나 해야 매출이 아닌 **이익**이 극대화되는가?
- 방법: 판매 데이터 분석으로 최적 할인율 산출
- 교훈: 많이 팔아도 마진이 줄면 이익 감소 → 데이터 기반 의사결정 필요

### 빅데이터 분석 파이프라인 5단계

```
데이터 소스 → 수집/정제 → 저장 → 분석 → API 제공
```

1. **데이터 소스**: 시스템 로그, DB 거래 데이터, IoT/RFID 기기 데이터, 사용 패턴
2. **수집/정제**: 불필요·누락 데이터 제거 (전처리/프리프로세싱)
3. **저장**: 데이터 레이크(원시 데이터) → 데이터 웨어하우스(변환된 데이터)
4. **분석**: 상관관계 분석·군집 분석 등 알고리즘 선택 → 모델 학습·반복 테스트
5. **API 제공**: 학습된 모델을 REST API로 서비스에 연동

### ETL 개념

**ETL = Extract(추출) → Transform(변환) → Load(적재)**
- 데이터를 변환하여 저장 공간에 쌓는 과정 전체를 지칭

### 주요 분석 기법

| 기법 | 설명 | 예시 |
|------|------|------|
| **상관관계 분석** | 두 변수 간 관계 강도 측정 | 날씨↑ → 아이스 아메리카노 판매↑ |
| **군집 분석** | 유사한 데이터를 그룹화 | 정상 패턴 vs 이상 패턴 분리 |
| **연관 규칙 분석** | 함께 발생하는 항목 발견 | 기저귀 → 맥주 구매 연관 |

### 소규모 구축 스택 (ELK + Python)

```
시스템 로그 파일
    ↓ Filebeat (파일 수집)
    ↓ Logstash (정제/변환)
    ↓ Elasticsearch (저장, 고속 검색)
    ↓ Python (분석 알고리즘 적용)
    ↓ FastAPI / Flask (API 제공)
    ↓ 실제 서비스 연동
```

- **Filebeat**: 로그 파일을 지속적으로 읽어 전송
- **Logstash**: 데이터 전처리 및 정제
- **Elasticsearch**: 고속 저장·검색 (데이터 레이크 역할도 가능)
- **Python**: 분석 알고리즘 구현 주력 언어
- **FastAPI/Flask**: 학습된 모델을 API로 서빙

### 주요 활용처

1. **수요 예측**: 지역·시간대별 판매량 예측 → 재고 최적화, 물류비 절감
2. **개인화 추천**: 사용자별 콘텐츠/상품 추천 → 체류 시간·전환율 향상
3. **장애 예측**: 정상 패턴에서 벗어난 이상 징후 감지 → 선제적 대응
