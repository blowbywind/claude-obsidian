## 요약

Claude Code를 전혀 모르는 초보자 대상의 설치·기초 활용 강의 (한국어). IDE를 "주방", Claude Code를 "셰프"로 비유해 개념을 설명. Windows 기준 설치부터 CLAUDE.md 설정, 블로그 글 자동 생성 데모까지 다룬다.

## 핵심 주장

- Claude Code 검색량이 2–3개월 사이 3배 상승, 해외에서도 급증 중
- IDE(주방) + Claude Code(셰프) 비유: IDE는 작업 공간, AI는 그 안에서 일하는 도구
- CLAUDE.md에 프로젝트 지시와 컨텍스트를 저장해두면 매 세션마다 설명 불필요
- **검증 가능한 데이터·결과물을 제공하면 아웃풋 품질이 크게 향상된다**
- AI 에이전트 워크플로우를 한번 구축해두면 반복 작업 속도가 빨라진다

## 영상 흐름

1. Claude Code 인기 상승 배경 소개
2. 추천 IDE 소개: 안티그래비티(Antigravity) — Google 제품, Gemini 연동 가능, 초보자 친화적
3. Windows 설치 실습 (다운로드 → 설치 → 한국어 설정 → 로그인)
4. CLAUDE.md 개념 및 설정 방법
5. 기초 활용: 샘플 텍스트 → 블로그 글 자동 생성 데모
6. 핵심 원칙: 검증 가능한 데이터 + 명확한 지시 = 더 나은 결과

## 주방/셰프 비유

| 비유 | 실제 |
|------|------|
| 주방 | IDE (작업 환경) |
| 셰프 | Claude Code, Gemini 등 AI |
| 요리 과정 | AI 에이전트 워크플로우 |

여러 AI(셰프)를 같은 주방(IDE) 안에서 사용 가능.
