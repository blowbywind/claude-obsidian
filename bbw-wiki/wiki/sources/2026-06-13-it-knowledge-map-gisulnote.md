## 요약

CS 전공자가 배우는 지식 체계를 비전공자·바이브코더가 이해할 수 있도록 전체 흐름을 마인드맵으로 설명. 소프트웨어 개발 구조부터 언어·프레임워크 구분, 컴퓨터 구조, 네트워크, 아키텍처, 클라우드·컨테이너까지 한 영상에 압축.

## 핵심 주장

### 1. 소프트웨어 개발 구조

**앱 종류**: 웹 / 앱(네이티브) / 하이브리드(겉은 앱, 안은 웹)

**프론트엔드 vs 백엔드**
- 프론트엔드: 사용자에게 보이는 화면 (웹화면, 앱화면)
- 백엔드: 서버 + 데이터베이스 (데이터 처리·저장)
- 통신으로 연결: 클라이언트 ↔ 서버

### 2. 언어 vs 프레임워크 구분

| 구분 | 예시 |
|------|------|
| **언어** | C, Java, JavaScript, Python |
| **프레임워크** | Spring/Spring Boot (Java), Node.js (JS 서버), React (JS 프론트) |

- **프레임워크**: 언어를 기반으로 개발을 쉽게 하도록 미리 만들어 놓은 틀
  - Spring Boot: 인증·응답·예외처리 등이 미리 구현됨
  - React: UI 컴포넌트 기반 화면 개발 틀
- **주의**: Java ≠ JavaScript (이름만 비슷, 완전히 다른 언어)

**프론트엔드 언어**: HTML + CSS + JavaScript (+ React 프레임워크)  
**백엔드 언어**: Java (Spring Boot), Python (FastAPI/Flask), JavaScript (Node.js)

### 3. 소프트웨어 공학 (방법론)

규모가 커질수록 규칙과 원칙이 필요 → 공학

**폭포수(Waterfall) 방법론**:
기획 → 분석·설계 → 개발 → 테스트 → 납품 (단방향, 되돌리기 어려움)

**애자일(Agile) / DevOps**:
지속적으로 기능을 추가·개선하는 서비스에 적합. 폭포수의 한계(완벽한 사전 기획 불가) 보완.

### 4. 컴퓨터 구조 계층

```
언어 → 프레임워크 → 프로그램
                          ↓ (실행 중)
                        프로세스
                          ↓ (처리)
                  프로세서(CPU)
                          ↓ (관리)
                     운영체제(OS)
```

- **프로그램**: 언어로 만든 결과물
- **프로세스**: 실행 중인 프로그램
- **프로세서(CPU)**: 프로세스를 처리하는 하드웨어
- **OS**: 프로그램들이 구동될 수 있게 하는 소프트웨어 (하드웨어 위에서 동작)

C언어는 프론트/백엔드 개발용이 아니라 **프로그래밍 본질(변수·조건문·반복문·함수·알고리즘) 학습**에 최적

### 5. 네트워크

- **HTTP**: 웹브라우저 ↔ 웹서버 통신 프로토콜 (약속)
- **HTTPS**: HTTP + 보안(Secure) — 현재 표준
- **IP**: 서버 주소 체계, 네트워크에서 목적지를 찾는 근본 규약
- **라우터/스위치**: 패킷(데이터 단위)의 흐름을 최종 목적지(서버)로 전달하는 장비

### 6. 아키텍처

여러 대의 서버를 어떻게 구성할지의 설계 = 아키텍처

**3-tier 아키텍처** (가장 일반적):
```
클라이언트 → 웹서버(화면) → WAS(로직) → DB(데이터)
```
- 1 tier: 보여지는 영역
- 2 tier: 비즈니스 로직 처리
- 3 tier: 데이터 저장

**MSA(마이크로서비스 아키텍처)**: 서비스를 작은 독립 단위로 분리

### 7. 클라우드 · 컨테이너

**핵심 원리: 가상화(Virtualization)**
물리 서버를 가상으로 분할 → 필요시 즉시 제공 가능 (AWS EC2 인스턴스 5분 내 생성)

**VM(Virtual Machine)**:
- OS를 포함한 가상 서버
- 무겁지만 완전한 격리

**컨테이너(Container)**:
- OS를 경량화하여 효율 극대화
- 대표 기술: **Docker**

**오케스트레이션**:
- 여러 컨테이너를 관리: **Kubernetes(쿠버네티스)**
