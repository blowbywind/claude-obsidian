## 요약

Meta 8년차 엔지니어 두 명(하재상·알렉스)이 FastCampus 공개 라이브에서 AI 시대 워크플로우 혁신을 논의한 1시간 29분 강연. 핵심 주장: "AI를 기존 워크플로우에 얹지 말고, 워크플로우 자체를 통째로 갈아엎어라." 위임 마인드셋·에이전트 프로덕티비티·컨텍스트 인텔리전스·세컨 브레인을 연결하는 실전 프레임워크를 제시한다.

## 핵심 주장

### 1. 위임하는 사람으로의 전환 (하재상)
- AI 시대의 모든 유행어(AI 네이티브, AI 오케스트레이터 등)의 공통 본질: **직접 코드를 짜는 사람 → 에이전트에게 위임하는 사람**
- 위임은 어색하고 힘든 일 — 직장에서 직급이 올라갈수록 필요한 스킬이지만, 처음에는 내가 직접 하는 것보다 오래 걸림
- 에이전트 위임이 사람 위임보다 유리한 점: 24시간, 동시 다중 작업, 감정 없음

### 2. 워크플로우 재정의 4단계 (Unlearn → Redefine → Execute → Iterate)
- **Unlearn**: 기존 워크플로우를 내려놓는다. "원래 이렇게 했으니까 AI 얹으면 되지"가 가장 흔한 함정
- **Redefine**: 내 업무를 다시 정의한다. 70%는 반복 작업(이메일·미팅·채팅 확인)임을 인식
- **Execute**: 일단 위임하고 돌린다. 처음에는 결과가 더 안 좋을 수 있음 — 정상
- **Iterate**: 결과 검증 → 프롬프트 수정 → 컨텍스트 정리 → 재실행 사이클 반복

### 3. 매일 반복하는 업무부터 시작할 것
- 측정하기 쉽다 (30분 → 5분처럼 직접 체감)
- 실수해도 데미지가 작다 (익숙한 영역이므로 즉시 검증 가능)
- 한 번에 다 갈아엎으려 하지 말고 하나씩

### 4. AI를 비서처럼: 아침 브리핑 예시
에이전트가 출근 전 30분 지하철 이동 중에 다음을 자동 정리:
1. 오늘 캘린더 일정 (시간순)
2. 펜딩 pull request / 미완료 작업
3. 온콜 신호
4. 관리 중인 프로젝트 상태
5. 중요 채팅 요약

단순 나열이 아니라 AI가 "오늘 이것부터 해야 한다"고 우선순위를 판단해서 전달.

### 5. 에이전트 프로덕티비티로의 전환
- 과거: Developer Productivity (내가 빨라지는 법)
- 현재: **Agent Productivity** (에이전트가 빨라지는 법)
- 인간 개발자 10배 향상 → 매우 어려움 / 에이전트 10배 향상 → 컨텍스트·도구·작업 분해만 바꿔도 가능
- 에이전트 생산성 투자 대상: 컨텍스트 정리, 패턴 인덱싱, 검증·피드백 루프 자동화, 병렬 작업 설계

### 6. 컨텍스트 엔지니어링이 에이전트 생산성의 핵심
- 같은 모델·도구·프롬프트라도 컨텍스트 구성에 따라 결과가 완전히 달라짐
- 모델과 하네스는 점점 좋아지지만, 컨텍스트 품질은 사람이 설계해야 함
- → [[wiki/concepts/context-intelligence|컨텍스트 인텔리전스]] 개념으로 연결

### 7. 세컨 브레인 = 안목지(暗默知)의 외재화
- 에이전트가 모르는 것은 코드 밖에 있는 정보: 암묵적 룰, 비즈니스 로직 맥락, 오래된 위키
- 에이전트는 신입보다 못함 — 팀 점심 대화, 옆자리 시니어 한숨 섞인 조언을 들을 수 없음
- 세컨 브레인 = 그런 암묵지를 글로 적어놓은 그릇

### 8. 컨텍스트 인텔리전스: "잘 담는게 아니라 잘 찾게"
- 5,000 페이지 위키를 신입에게 주면 없는 것과 같음 → 에이전트도 동일
- **컨텍스트 인텔리전스**: 세컨 브레인에 구조(Structure)와 인덱스를 부여해 필요할 때 필요한 조각만 로드
- 인덱싱 3단계: ① 모든 파일 수집 → ② 모듈·주제·서비스 단위로 쪼개기 → ③ 각 조각에 메타데이터 부여
- **실제 사례**: 팀 서비스 작업 2시간 → 컨텍스트 인텔리전스 적용 후 30분 (4배 단축)

### 9. Q&A 주요 내용
- **온톨로지**: 정보의 개념과 관계성을 설명하는 역학. 컨텍스트 인텔리전스의 상위 개념
- **서브에이전트 타이밍**: 메인 컨텍스트 50% 이상 찼을 때 분기. 병렬 처리 필요한 단순 반복 작업에 유리
- **보안**: Security(엔트로픽 유출 우려)는 과도한 걱정. Privacy(내부 개인정보)는 트레이드오프가 실재함

### 10. AI Native Company (만담 섹션)
- ClickUp CEO: 22% 레이어오프 단행 — 재정 문제 아닌 AI 도입이 이유
- Meta도 같은 시기 레이어오프
- 실리콘밸리 인사이트: AI로 대체되는게 아니라 AI 잘 쓰는 팀이 더 적은 인원으로 더 많은 일을 하게 됨
