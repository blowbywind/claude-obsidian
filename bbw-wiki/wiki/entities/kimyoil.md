## 개요
1인 기업 "린네이티브(Lean Native)" 대표. 헤르메스 에이전트 5명 + Claude Code 에이전트 5명으로 구성된 AI 네이티브 팀을 실제 운영하며, 옵시디언 위키를 에이전트 간 맥락 공유 시스템으로 활용하는 방법론을 유튜브(@김요일)로 공개. 중소기업 대상 AI 네이티브 도입 컨설팅도 제공.

## 주요 활동

### 루프 설계 방법론 공유
"프롬프트를 잘 쓰는 시대 → 루프를 잘 설계하는 시대"로의 전환을 설명. Boris Cherny의 "그냥 요리하게 놔둬라(Let it cook)" 발언을 해설하며 loop.md 패턴을 실무 언어로 소개.

### AI 네이티브 팀 운영
- 헤르메스 5명(린네이티브) + Claude Code 5명(린 프로젝트) = 10명 AI 직원 팀
- 크론잡 야간 자율 학습 루프 설계·운영
- 옵시디언 위키로 모든 에이전트 간 맥락 공유

### 실제 제작 서비스
- **유튜브 쇼츠 조회수 급상승 실시간 수집 사이트** — 에이전트 5명 협업 제작
  - 효리(UI) + 효1(개발) + 효3(검증) + 효나(데이터) + 김요일(기획·감독)

### AI 네이티브 ERP 구상
- 기존 ERP + 옵시디언 위키 통합 = 전 직원이 AI 에이전트를 보조 직원으로 사용하는 구조
- 대시보드·태스크·메신저·에이전트 현황·토큰 대시보드 포함 설계 완료 (미출시)
