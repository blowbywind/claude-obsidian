## 개요
2026년 1월 출시된 오픈소스 로컬 AI 에이전트. "당신의 기기에서 직접 실행하는 개인 AI 어시스턴트"를 표방하며, 이미 사용하는 채팅 채널(Telegram, Slack, Discord 등)에 연결해 AI를 사용할 수 있는 셀프호스팅 게이트웨이다. 출시 직후 폭발적 GitHub 성장을 기록해 오픈소스 역사상 가장 빠르게 성장한 저장소 중 하나가 됨.

## 주요 특징
- **로컬 퍼스트**: 게이트웨이·툴·메모리가 자신의 기기에 저장 (SaaS 아님)
- **멀티 채널**: Telegram, Slack, Discord, WhatsApp, iMessage, LINE 등 22개+ 채널 지원
- **AI 모델 유연성**: Anthropic, OpenAI, Google 클라우드 모델 또는 Ollama/LM Studio 로컬 모델 모두 연결 가능
- NVIDIA NemoClaw와 공식 연동 지원

## 헤르메스와의 관계
김요일이 영상에서 "오픈 클로와 유사한 로컬 에이전트"로 헤르메스를 소개. 두 도구 모두 로컬 설치 + 메시징 채널 연결 + 멀티 AI 모델 지원 패턴을 공유.
