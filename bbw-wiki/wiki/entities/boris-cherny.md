## 개요

Anthropic Staff Engineer. Claude Code 창시자. 2026년 1~2월에 42가지 Claude Code 실전 팁과 실제 CLAUDE.md 파일을 공개했다. '자기학습 루프'와 '병렬 서브 에이전트로 하루 100개 PR' 방법론으로 알려져 있다.

## 주요 기여

- **42가지 팁**: 2026년 1~2월 공개, Claude Code 실전 워크플로우의 핵심
- **CLAUDE.md 황금 규칙**: 작게 시작하고 실수마다 규칙 추가 (자기학습 루프)
- **병렬 작업 시스템**: 서브 에이전트로 독립 작업 동시 실행 → 하루 100개 PR 달성
- **루프 철학**: "내가 클로드 코드에게 계속 프롬프트하는 게 아니라 클로드가 스스로 프롬프트하게 내버려 둔다" / "그냥 요리하게 놔둬라(Let it cook)" — 프롬프트 → 루프 설계로의 패러다임 전환 제안자
