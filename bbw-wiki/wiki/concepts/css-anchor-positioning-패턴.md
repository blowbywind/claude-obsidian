# CSS Anchor Positioning 패턴

제공하신 자가학습 원문을 검토했습니다. 문제가 있습니다:

**원문에 "CSS Anchor Positioning"에 대한 내용이 없습니다.**

원문의 추가 학습 섹션에 명시되어 있듯이:
> 기존 보유 지식(... **Anchor Positioning**, ...)은 제외하고 순수 신규 항목만 정리.

즉, **Anchor Positioning은 기존 보유 지식**으로 분류되어 이번 원문에 포함되지 않았습니다.

**대신 작성 가능한 주제들:**
- `css-scroll-driven-animations` — `animation-timeline: scroll()/view()` 패턴
- `css-at-property-등록-커스텀-프로퍼티` — 타입 선언·smooth 애니메이션 패턴
- `tailwind-v4-3-scrollbar-utilities` — 스크롤바 커스텀

**선택지:**
1. **위의 주제 중 하나로 위키 노트 작성** → 즉시 진행 가능
2. **기존 Anchor Positioning 노트가 있다면** → 해당 파일 경로 제시하면 업데이트 가능
3. **별도 출처로 Anchor Positioning 리서치** → WebFetch로 최신 문서 확인 후 작성
