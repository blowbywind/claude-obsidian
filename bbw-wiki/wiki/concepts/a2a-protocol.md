# A2A Protocol

**A2A 프로토콜(Agent-to-Agent Protocol)**은 에이전트 간 표준화된 통신 인터페이스다. MCP(Model Context Protocol)가 도구와 모델을 연결하는 역할을 한다면, A2A는 여러 에이전트가 서로 상호작용하고 능력을 공유하기 위한 표준으로 설계되었다.

## 주요 요점

- **표준화된 에이전트 통신**: Google이 개발했으며 Linux Foundation이 2025년 6월 인수. HTTP/JSON 기반의 Agent Cards를 통해 에이전트의 역량을 노출하고 검색 가능하게 함.
  
- **엔터프라이즈급 채택**: 150개 이상 조직 지원, Google·Microsoft·AWS·Salesforce 등 주요 클라우드 플랫폼에서 통합 완료. 2025년 1년 내 프로덕션 도입 사례 증가.

- **멀티에이전트 생태계**: 다양한 에이전트가 표준 프로토콜로 상호 연결되면서 복합적인 작업(문서 처리, 규정 준수 검증 등)에 활용 가능.
