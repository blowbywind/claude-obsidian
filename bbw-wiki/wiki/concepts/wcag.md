# `wcag

## WCAG 노트 본문

**웹 접근성 지침(Web Content Accessibility Guidelines)**은 장애인을 포함한 모든 사용자가 웹 콘텐츠에 동등하게 접근할 수 있도록 W3C가 정의한 국제 표준이다. WCAG 2.2는 인지·운동·시각·청각 장애 사용자의 접근성을 보장하기 위해 인식 가능성, 조작 가능성, 이해 가능성, 견고성 4대 원칙으로 구성되어 있다.

### 포커스 인디케이터 설계 (SC 2.4.11)
포커스 인디케이터는 키보드 사용자가 현재 위치를 파악하는 필수 UI 요소다. WCAG 2.2 Success Criterion 2.4.11은 포커스 인디케이터의 최소 면적을 규정한다: 테두리 경우 1 CSS px 이상(둘레 기준), 또는 최단 변 4 CSS px 이상이어야 한다. 인접한 비포커스 색과의 명도 대비 최소 3:1을 유지해야 시각적 구분이 명확하다.

### 키보드 네비게이션 UX
`:focus-visible` 의사 선택자 사용이 현행 베스트 프랙티스다. 마우스 클릭 시 포커스 링을 제거하되 키보드 탐색 시에만 표시함으로써 마우스 사용자의 시각적 혼란을 줄이면서도 키보드 사용자의 접근성을 보장한다.

### 문맥과 적용
키보드 전용 사용자, 운동 장애 사용자, 시각보조 기술(스크린 리더) 의존 사용자 등 다양한 접근성 요구에 대응한다. AA 레벨 이상 준수가 대부분의 조직 및 공공 기관 표준이다.
