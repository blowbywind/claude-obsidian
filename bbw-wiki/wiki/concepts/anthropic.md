# `anthropic

Anthropic은 Claude 대규모 언어 모델(LLM)과 이를 기반한 AI 에이전트 제품을 개발하는 AI 안전 중심 회사다.

**핵심 요점:**

1. **Claude Code의 시장 지배** — JetBrains 조사(10년+ 경력 개발자)에서 46%가 Claude Code 선택(Copilot 9%), SWE-bench Verified 80.8%로 최고 성능 달성. 프로그래밍 에이전트 시장에서 기술 우위 확보.

2. **Cowork로 일반 컴퓨팅 확장** — 2026년 Claude Code를 스프레드시트, 파일관리, 보고서 작성 등 프로그래밍 외 영역으로 확장한 Anthropic Cowork 발표. 에이전트 기술의 범용화 전략 신호.

3. **Claude Fable 5 공개 모델화** — 2026-06-09 공개 모델 Fable 5 출시(SWE-Bench Pro 80.3%), GPT-5.5(58.6%)·Gemini 3.1 Pro(54.2%) 대비 우월. API 가격 $10/M input·$50/M output으로 접근성 제고.

4. **파트너십을 통한 엔터프라이즈 확보** — 6월 중순 DXC·TCS와 글로벌 파트너십 체결로 Fortune 500·규제산업 대상 Claude 리셀러·구현 채널 확보.
