# Claude Code Tools

Claude Code에서 에이전트가 사용하는 빌트인 도구 모음.

## 주요 도구

| 도구 | 용도 |
|------|------|
| Read | 파일 읽기 |
| Write | 파일 쓰기 (신규) |
| Edit | 파일 수정 (diff) |
| Bash | 쉘 명령 실행 |
| Grep | 내용 검색 |
| Glob | 파일 패턴 검색 |
| Agent | 서브에이전트 호출 |
