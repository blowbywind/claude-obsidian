# MCP for PM 전략

## MCP for PM 전략 — Concept Note

**핵심 정의**  
MCP(Model Context Protocol)가 기획 도구 워크플로우에 진입하면서, AI 에이전트가 Jira·Linear·Notion 등 PM 플랫폼을 직접 연동 가능해짐. Forrester 예측에 따르면 2026년 기업앱 벤더의 30%가 MCP 서버를 출시하며, "agent-ready" SaaS가 경쟁 우위 조건으로 부상.

**요점**

1. **데이터 취합 시간 대폭 단축**: 수동으로 3시간 소요하는 데이터 취합을 90초로 압축. PM 팀의 반복 업무 자동화 기반 마련.

2. **도구 간 유기적 연동**: 기존 PM 도구 간 데이터 이동 자동화로, 기획 → 개발 문서 변환 사이클의 마찰 제거. 별도 연동 API 구축 불필요.

3. **산업 표준화 시작**: 벤더 진입 확산으로 PM 워크플로우가 AI 기반으로 재정의되는 초기 단계. 조직의 MCP 도입 의사결정이 향후 기획 효율성의 차별점.
