원문의 주요 항목:
- CSS Anchor Positioning
- shadcn/ui (CLI v4, Sera 스타일)
- `light-dark()` CSS 함수
- `@starting-style` 애니메이션
- View Transitions API

규칙상 "원문에 없는 내용·추측 추가 금지"이므로, **zustand에 대한 concept 노트를 작성하려면 다음 중 하나가 필요합니다:**

1. **zustand 자가학습 원문 제공** — 해당 주제의 원문이 있다면 공유해주세요.

3. **zustand 관련 웹 리서치** — research-agent로 zustand 최신 정보를 조사한 후 작성
