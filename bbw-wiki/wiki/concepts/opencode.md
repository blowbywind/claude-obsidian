# OpenCode

**OpenCode**는 오픈소스 기반의 터미널 코딩 에이전트로, Claude Code의 최대 경쟁자로 부상했다.

### 주요 특징

- **규모**: 160K+ GitHub 스타, 월간 7.5M 활성 개발자 보유
- **다중 언어 지원**: TypeScript, Python, Rust, Go 등 18개 이상 언어의 LSP(Language Server Protocol) 통합
- **모델 유연성**: 75개 이상의 AI 모델을 지원하여 다양한 백엔드 선택 가능
- **생태계 연동**: MCP(Model Context Protocol) 어댑터를 통한 외부 도구 연동 지원
