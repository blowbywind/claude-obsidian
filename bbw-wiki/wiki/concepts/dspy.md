# `dspy

DSPy(Data Science Programming framework)는 Stanford 연구팀(Omar Khattab 주도)이 개발한 프롬프트 최적화 프레임워크입니다. 개발자가 수동으로 프롬프트 문구를 반복 수정하는 대신, 데이터셋을 입력하면 시스템이 자동으로 최적 명령어를 합성·최적화합니다.

**핵심 요점:**
- **자동 프롬프트 최적화**: 데이터셋 기반으로 LLM 명령어를 체계적으로 조율해 수동 튜닝 반복을 제거합니다.
- **테스트 시나리오 적용**: 테스트 프롬프트 생성 시 DSPy로 자동 최적화하면, 테스트 레퍼토리 개선 주기를 단축합니다.
- **선언적 프로그래밍**: "어떻게"가 아닌 "무엇"을 달성할지 정의하면, 프레임워크가 최적 실행 경로를 찾습니다.
- **비용 절감**: 프롬프트 엔지니어링 비용을 데이터 준비와 평가 중심으로 재배분합니다.
