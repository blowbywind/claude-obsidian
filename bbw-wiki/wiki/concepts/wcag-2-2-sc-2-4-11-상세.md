# WCAG 2.2 SC 2.4.11 상세

자가학습 원문을 기반으로 WCAG 2.2 SC 2.4.11 상세 노트의 본문을 작성합니다.

---

## 핵심 정의

**Focus Not Obscured (Minimum)** 는 WCAG 2.2 레벨 AA 기준으로, 키보드 포커스를 받은 UI 요소가 저자(author) 콘텐츠에 의해 **완전히 가려져서는 안 됨**을 규정합니다.

## 요점

1. **완전 가림 금지, 부분 가림 허용**: 모달 대화상자, 고정 헤더, 쿠키 배너 같은 콘텐츠가 포커스 요소를 일부 가리는 것은 AA에서 허용됩니다. 완전 미가림(Zero Obscuration)을 요구하는 것은 더 엄격한 AAA 기준 SC 2.4.12입니다.

2. **스크롤 보정 기법**: `scroll-margin-top` CSS 속성이나 포커스 이벤트 핸들러에서 프로그래밍 방식 스크롤을 통해 포커스된 요소를 화면 상단으로 위치시켜 준수할 수 있습니다.

3. **키보드 네비게이션 보장**: 저시력 사용자나 운동장애가 있는 사용자가 키보드만으로 콘텐츠에 접근할 때, 포커스 위치를 항상 시각적으로 확인할 수 있어야 합니다.
