# `MCP Streamable HTTP`

노트 본문(frontmatter·h1 제외)을 마크다운으로 작성했습니다:

```markdown
## 핵심 정의

**MCP Streamable HTTP**는 기존 SSE(Server-Sent Events) 기반 전송 방식을 대체하는 stateless HTTP 전송 표준으로, 로드 밸런서 배후의 분산 환경에서 작동하도록 설계된 MCP(Model Context Protocol) 전송 계층이다.

## 특징

- **무상태 전송 방식**: 기존 SSE의 연결 상태 의존성을 제거하여 로드 밸런싱 친화적 아키텍처 구현
- **엔터프라이즈 수평 확장**: 여러 MCP 서버 인스턴스 간 stateless 상태 유지로 수평 확장 가능
- **표준화 추진**: 2026년 기준 엔터프라이즈급 MCP 표준으로 논의 중인 차세대 전송 방식

## 출처

```
