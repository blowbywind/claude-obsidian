# `scroll

제공된 자가학습 원문에 **"scroll" 관련 내용이 없습니다**.

원문 구성:
- Tailwind v4 Container Queries
- shadcn/ui Radix/Base UI 통합
- WCAG 2.2 새 기준들 (타깃 크기, 드래그 대안)
- CSS Anchor Positioning
- View Transitions API
- 유럽 접근성법(EAA)

규칙상 원문에 없는 내용은 추가할 수 없으므로, 다음 중 선택해주세요:

1. **다른 자가학습 원문 제공** — scroll 주제를 다룬 메모가 있으면 공유
2. **원문에서 scroll 관련 발췌** — 위 목록 중 scroll과 관련된 부분이 있는지 확인 (예: View Transitions의 스크롤 동작?)
3. **주제 변경** — 위 원문에서 다른 concept 노트 작성 (예: container-queries, wcag-2.2-updates, css-anchor-positioning 등)
