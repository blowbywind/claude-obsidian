# LangGraph

LangGraph는 LangChain에서 개발한 **멀티에이전트 오토노마스 워크플로 프레임워크**다. v0.4(2026-04) 기준으로 상태 지속성과 human-in-the-loop 체크포인트 기능을 강화하여 프로덕션급 에이전트 시스템의 실행 엔진으로 자리잡았다.

### 핵심 특성

- **상태 관리 및 지속성**: 에이전트 상태를 저장·복구하여 장시간 워크플로와 중단/재개 시나리오 지원
- **Human-in-the-Loop 체크포인트**: 에이전트 판단 지점에서 인간 승인을 삽입 가능한 거버넌스 체계
- **멀티에이전트 표준 런타임**: 모든 LangChain 에이전트의 기본 실행 엔진으로 채택 확정 (Python/JavaScript 지원)
- **생태계 점유율**: GitHub 3만 스타 돌파, 같은 역무의 CrewAI를 추월한 업계 사실상 표준
