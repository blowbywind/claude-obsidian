# `concepts/progressive

확인 필요합니다. 원문을 검토한 결과 **"`concepts/progressive`" 주제가 명시되지 않았습니다**. 

원문의 내용은:
- GitHub Actions 액션 SHA 고정, OIDC 인증
- distroless 이미지, Cosign 서명
- OTel 컨테이너 관측성
- **Blue-Green/Canary 배포 전략** ← 여기가 "progressive"와 관련 가능성
- SBOM, SLSA, 이미지 스캔(Trivy/Grype)

**다음 중 어느 것을 의도했는지 확인 부탁**:

1. **`concepts/progressive-deployment`** — Canary 배포처럼 트래픽을 단계적(progressive)으로 증가시키는 전략?
2. **다른 주제** — 원문의 어느 부분을 "progressive"로 위키화할지?
3. **오타/제목 수정** — 다른 주제명으로 변경?

명확해지면 규칙에 맞춰 300~700자, 핵심 정의→요점 2~4개→출처 URL 구조로 작성하겠습니다.
