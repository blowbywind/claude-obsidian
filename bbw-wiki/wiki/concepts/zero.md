## 📝 마크다운 본문 (300~700자)

```markdown
Zero Trust for AI는 AI 에이전트와 플러그인에 대해 **최소 권한 원칙**을 적용하는 보안 개념입니다. Microsoft에서 공식화한 지침으로, 신뢰하지 않는 기본 가정 하에서 AI 도구의 권한을 엄격하게 제한합니다.

## 요점

**1. AI 에이전트·플러그인 최소 권한 원칙**
모든 AI 에이전트와 플러그인은 필요한 최소 권한만 부여받아야 하며, 과도한 접근 권한을 제한합니다. 이는 기존 "AI Agent Governance 체크리스트"의 외부 근거로 작용합니다.

**2. PRD 보안 섹션 표준화**
Microsoft의 공식 가이드로서 PRD 에이전트 보안 섹션에 의무화할 만한 신뢰도 높은 출처입니다. "PRD 에이전트 보안 섹션 의무화" 정책의 외부 근거로 유효합니다.

**3. 엔터프라이즈 신뢰성**
Microsoft Security Blog에서 발행한 공식 가이드로, 엔터프라이즈 환경에서의 신뢰성이 검증됐습니다.

## 출처
```
