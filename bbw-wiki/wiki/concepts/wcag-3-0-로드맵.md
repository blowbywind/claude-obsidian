# WCAG 3.0 로드맵

**핵심 정의**:
WCAG 2.2는 접근성 웹 콘텐츠 가이드라인의 최신판으로, 기존 WCAG 2.1에 6개의 새로운 성공 기준을 추가해 모바일·인터랙티브 요소 중심으로 강화되었습니다.

**요점**:

1. **새로운 성공 기준 (AA 등급)**
   - SC 2.5.8: 인터랙티브 요소(버튼·링크) 최소 크기 **24×24 CSS px**
   - SC 2.5.7: 드래그 인터랙션 시 탭·클릭 등 대체 수단 필수 제공

2. **규제 및 준수 의무**
   - EU 접근성법(EAA) 2025년 6월 28일 발효로 **WCAG 2.1 AA** 준수 의무화
   - 미준수 시 연매출 4% 또는 €10만 이하 과징금

3. **표준 진화 방향**
   - EN 301 549(유럽 표준)가 WCAG 2.2로 업데이트되고 있으며, 국제 기준 수렴 진행 중
