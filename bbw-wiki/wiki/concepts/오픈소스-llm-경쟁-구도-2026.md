# 오픈소스 LLM 경쟁 구도 2026

다음이 요청하신 concept 노트 본문입니다:

---

## 핵심 정의
2026년 6월 기준 오픈소스 LLM이 클로즈드 모델의 성능 격차를 급격히 좁혀가는 기술·시장 전환점. 중국 오픈소스 랩의 코딩/추론 성능 향상과 로컬 배포 가능 모델의 API 대체 현실화가 핵심 동인.

## 주요 요점

**글로벌 모델 성능 재편성**
- GLM-5.2(오픈웨이트)가 처음으로 SWE-Bench Pro에서 GPT-5.5를 추월, 1M 토큰 컨텍스트 지원
- Claude Opus 4.8 코딩 1위 유지(SWE-bench Verified 88.6%), Grok 4(75%) 대비 명확한 우위 확인

**로컬 배포 모델의 API 대체 현실화**
- Nemotron 3 Ultra(550B, 완전 허용), MiniMax M3(1M 컨텍스트, SWE-bench Pro 59%), Kimi K2.7 Code(1T 파라미터) 출현으로 클로즈드 모델 격차 급속 축소

**중국 오픈소스 랩의 추론·코딩 격차 추격**
- DeepSeek V4 Pro(MIT), Qwen 3.7 Max 등 글로벌 성능 추격 중
- 기존 라우팅 원칙(복잡 코딩→Claude)은 유효하나, 로컬 배포·비용 최적화 시나리오에서 오픈소스 대안 선택지 확대
