# 에이전틱 개발 보안(ADS)

자가학습 원문을 기반으로 "에이전틱 개발 보안(ADS)" 개념 노트 본문을 작성하겠습니다.

---

## 핵심 정의

자율 코딩 에이전트가 사용하는 **MCP 서버·런타임 도구·생성 코드 3계층을 종합 감시하는 보안 레이어**입니다. 에이전트 기반 개발 환경에서 신뢰할 수 없는 도구 호출, 악의적 코드 생성, 런타임 이탈 등의 위험을 구조적으로 제어합니다.

## 요점

1. **3계층 모니터링**: MCP 서버 권한 격리 → 런타임 도구 접근 제한 → 생성 코드 정적·동적 분석의 깊이 있는 감시 구조

2. **1급 아키텍처 요소**: 멀티에이전트 시스템 설계 시 "도구 감사(tool audit)" 레이어를 보안 정책과 동등한 수준으로 포함해야 에이전트 확산에 대응 가능

3. **에이전트-인프라 보안 파리티**: 인프라 정책(RBAC, 네트워크 정책)처럼 에이전트 권한 경계를 명시하고 감시하는 패턴 정립
