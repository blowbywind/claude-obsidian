# 에이전트 루프 비용 패턴

마크다운 본문:

## 핵심 정의

2025년→2026년 LLM API 가격이 80% 급락하면서 에이전트 루프의 모델 선택 가중치가 재편성되는 패턴. 기존의 비용 기반 다운그레이드에서 **태스크 적합도를 1순위, 비용을 2순위**로 전환하는 설계 원칙.

## 요점

**1. 가격 신호 약화**  
API 비용이 급락하면서 "비용이 높으니 더 싼 모델로 대체"라는 의사결정이 더 이상 경제적 우선순위가 아님. Claude Opus 4.5가 SWE-Bench 80.9%로 1위이고, 로컬 배포·프라이버시 요건이 없다면 성능 격차가 비용 절감보다 중요.

**2. 하이브리드 라우팅 모델**  
MS Agent Framework 1.0(2026.04 stable)의 권장 사항: 결정론적 워크플로를 기본으로 하되, 진정으로 가변적인 결정 지점에만 동적 라우팅 적용. Conductor 같은 YAML 기반 선언적 오케스트레이션으로 워크플로를 diff 가능하게 관리.

**3. 컨텍스트 엔지니어링 우선**  
비용 패턴의 핵심은 "어떤 모델을 선택할가"에서 "각 서브에이전트가 매 호출에서 무엇을 보는가"로 초점 이동. 오케스트레이터가 무관 정보를 걸러 핵심만 반환해 정보 밀도를 높이는 것이 토큰 절감의 실질적 수단.
