# AI 코딩 도구 시장 지형도 2026

## AI 코딩 도구 시장 지형도 2026 — 노트 본문

2026년 AI 코딩 도구 시장은 GitHub Copilot 중심에서 다중 플레이어 경쟁 구도로 재편됐다. JetBrains 조사(2026) 기준 시장 점유율은 Copilot 29%, Cursor 18%, Claude Code 18%로 상위 3개 도구의 점유율 격차가 축소됐다.

**주요 특성:**

1. **가격 정책 분화**: GitHub Copilot은 6월부터 $10 플랜을 월 1,500 크레딧 제한으로 변경하며 프리미엄 수익화 강화. Cursor는 연 $192 또는 종량제, Claude Code는 클로드 구독 통합 형태로 차별화.

2. **경험층별 선호도**: 10년+ 경력 시니어 개발자의 46%가 Claude Code를 일상 도구로 선택해, 경험이 깊을수록 도구 다양성 증가 추세.

3. **Cursor 성장 모멘텀**: 2025년 1월 $100M → 11월 $1B → 2026년 2월 $2B ARR로 역사상 가장 빠른 SaaS 성장 사례 중 하나.
