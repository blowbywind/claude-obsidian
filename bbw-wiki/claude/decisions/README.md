# Architecture Decision Records

중요한 기술 결정을 내릴 때마다 여기에 기록합니다.
"왜 그렇게 했는지"를 나중에 찾아볼 수 있습니다.

## 파일명 규칙
`YYYY-MM-DD-결정-제목.md`

## 기록 기준
- 라이브러리/도구 선택
- 아키텍처 변경
- 보안 설정 변경
- 되돌리기 어려운 결정

## ADR 작성 체크리스트

새 ADR 작성 완료 후 아래 항목 확인:

- [ ] 결정 이유 (Why) 명시
- [ ] 제약 조건·트레이드오프 기록
- [ ] 재발 방지 규칙이 있다면 → **active-rules 반영 여부: Y / N**
  - Y: `~/.claude/memory/active-rules.md`에 추가 완료
  - N: 미반영 이유 명시 (예: 프로젝트 한정, 이미 반영됨 등)
