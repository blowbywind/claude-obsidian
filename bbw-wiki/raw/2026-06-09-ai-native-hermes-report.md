## 1. AI 네이티브 팀 구성

### 헤르메스 에이전트 (텔레그램 연결, 야간 자율 학습 담당)

| 에이전트 | 역할 |
|---|---|
| 효율이 (효1) | 개발 + 다른 에이전트 업무 취합·보고 (오른팔, 모더레이터) |
| 효리 (효2) | 디자인 — 웹사이트 UI, 앱 UI, PPT 슬라이드 |
| 효삼이 (효3) | 자동화 + 효1 개발 서포트·검증 (Claude Code 연결) |
| 효나 (효4) | 콘텐츠 — 이미지/영상 생성, 카드뉴스, SNS, 유튜브 크롤링 |
| 효정이 (효5) | 강의 보조 — 리서치, 슬라이드 제작, 커뮤니티 운영, 일정 관리 |

### Claude Code 에이전트 (주간 업무 담당)

| 에이전트 | 역할 |
|---|---|
| 시원 (C1) | 오케스트레이터 — 다른 에이전트에 업무 지시 후 최종 보고 |
| C2, C3, 신하 등 | Plan 모드 기획, 스킬 제작, 연결 작업 |

> **분리 이유**: 주간 업무 중 헤르메스 에이전트에게 혼선을 주지 않기 위함.
> 헤르메스 = 에이전시 / Claude Code = 인하우스 개념

## 2. 헤르메스를 선택한 이유 (5가지)

1. **모바일 원격 실행** — 언제 어디서나 텔레그램으로 에이전트 실행
2. **멀티 에이전트 무한 증식** — 고유 ID를 가진 개별 에이전트 생성 (단순 대화창 복제 아님)
3. **크론잡(예약 작업)** — 정해진 시간에 루틴 업무 자율 수행
4. **로컬 데이터 접근 + 비동기 작업** — 외부에서 로컬 파일 요청 시 텔레그램으로 전송, 완료 후 알림
5. **장기 기억 + 학습 루프** — 한번 말한 것을 잊지 않고, 업무할수록 스스로 성장

## 3. 야간 자율 학습 루프 설계

### 핵심 아이디어
> "우리가 자는 시간을 활용한다"

### 에이전트별 학습 방법

**효율이 (개발)**
- 실리콘밸리 개발자 논문·학술 자료
- AI 뉴스, 레딧, AI 블로그·커뮤니티
- 학습 깊이: 1~10 기준으로 설정
- 결과: 기상 시 방대한 학습 완료 상태

**효리 (디자인)**
- Dribbble, Awwwards, Mobbin, Godly 등 UI 레퍼런스 사이트 주기적 탐색
- 감각적 기업·브랜드의 공개 디자인 시스템 학습
- **OpenDesign** (Claude Design 로컬화 오픈소스) — CLI로 연결해 무한 반복 실습
  - 레퍼런스 전달 → "95% 이상 똑같이 만들 때까지 무한 루프" → 취침

## 4. 맥락 공유 시스템 — 옵시디언 위키

### 왜 옵시디언인가
- 매일 밤 방대한 리서치 결과를 전부 메모리에 저장하면 **메모리 초과 → 에이전트 성능 저하**
- 해결책: 분석·학습 완료 → **옵시디언 위키화** → 메모리는 최대 효율 유지

### 에이전트 규칙 (못 박아두는 것)
```
1. 분석·학습 후 반드시 옵시디언에 위키화
2. 메모리는 항상 최대 효율 유지
3. 관련 업무 시 키워드로 옵시디언 검색 후 참조
```

### 핵심 효과
- 헤르메스 5명 + Claude Code 5명이 **같은 옵시디언 위키 공유**
- Codex, Claude Code, Gemini 등 어떤 도구를 사용해도 **위키만 있으면 맥락 즉시 연결**
- 에이전트끼리 Session Send(AI 간 대화)로 업무 지시·보고

## 5. 실제 작업물 예시

**유튜브 조회수 급상승 쇼츠 실시간 수집 사이트**
- 효리: UI 디자인
- 효1: 개발
- 효3: 검증
- 효나: 유튜브 정책·데이터 확인
- 향후 계획: 크론잡으로 자가 점검·수정, UX 리서치 자동화

## 6. 자동화 설정

- **3시간마다 자동 커밋 + 옵시디언 저장** (크론잡) — 작업 중 커밋 누락 방지
- **행동 기준 규칙(CLAUDE.md 유사)** — 에이전트마다 해야 할 것 / 하지 말아야 할 것 사전 약속

## 7. AI 네이티브 ERP 구상

옵시디언 위키를 ERP에 통합하면 전 직원이 AI 에이전트를 보조 직원으로 사용하는 구조:

| 기능 | 내용 |
|---|---|
| 대시보드 | 전체 업무 한 눈에 |
| 태스크 뷰 | 세부 일정 확인 |
| 메신저 | 직원 + 에이전트 통합 대화 |
| 에이전트 현황 | 예약 작업 모니터링 |
| 채널 연결 | 외부 흐름 원클릭 연결 |
| 스킬 인벤토리 | 사용 가능한 스킬·플러그인 목록 |
| 토큰 대시보드 | 작업별 토큰 사용량 분석 |

## 8. 핵심 인사이트

### "맥락 공유 시스템의 힘 = 진정한 에이전틱 엔지니어링"

1. **분리와 집중**: 에이전트도 폴더처럼 집중 환경이 필요 (헤르메스/Claude 분리)
2. **자는 시간 활용**: 크론잡 + 학습 루프 = 기상 시 레벨업된 에이전트
3. **메모리 관리**: 옵시디언 위키화로 메모리 효율 유지
4. **도메인 학습 투자**: 처음 세팅에 물리적 시간 투자는 불가피, 이후 자동화로 보상
5. **개발 과잉 영역 활용**: AI 개발자도 예상 못한 활용법이 무한히 존재
